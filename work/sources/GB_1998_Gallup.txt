NOTE on the 1998 row: as printed/extracted, the Democratic figure
reads "54.8", which is internally inconsistent (54.8 + 48.2 = 103,
and the printed advantage is 3.6). The release's own text states the
allocated 1998 result as 51.8% to 48.2% (51.8 - 48.2 = 3.6), so
"54.8" appears to be a typographical error on the page for 51.8.
Gallup's later uniform table (2004 release, "Gallup Final
Pre-Election Generic Ballot, 1994-2004") lists 1998 as 50.0 / 50.0.
See POLL_SOURCES_MEMO.md for how this disagreement was handled.
